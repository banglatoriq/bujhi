# বুঝি — ডেটা কালেকশন টুল

সাবজেক্ট বাছবে → এক ক্লিকে ওই সাবজেক্টের সব টপিক ও প্রশ্ন নামবে →
অ্যাপে বসানোর মতো SQLite ফাইল বেরোবে।

## ১. VS Code প্রস্তুতি

Extensions (`Ctrl+Shift+X`) থেকে ইনস্টল করো:

| এক্সটেনশন | কেন |
|---|---|
| Python (Microsoft) | ইন্টারপ্রেটার ও ডিবাগিং |
| Pylance | অটোকমপ্লিট |
| SQLite Viewer | নামানো `bujhi.db` চোখে দেখার জন্য |

`File → Open Folder` → `bujhi-scraper` ফোল্ডার খোলো।

## ২. একবারের সেটআপ

টার্মিনাল খোলো (`` Ctrl+` ``):

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

`(.venv)` দেখালে ঠিক আছে। তারপর:

```bash
pip install -r requirements.txt
```

`Ctrl+Shift+P` → `Python: Select Interpreter` → `.venv`-এরটা বাছো।

## ৩. চালানো

```bash
streamlit run app.py
```

ব্রাউজারে `http://localhost:8501` খুলবে। বন্ধ করতে টার্মিনালে `Ctrl+C`।

## কাজের ধাপ

### ধাপ ১ — সাবজেক্ট আনা

উপরে **🔄 সাবজেক্ট আনো** চাপো। সাইট থেকে সব সাবজেক্ট আর প্রতিটার
প্রশ্নসংখ্যা চলে আসবে।

প্রথমবার যদি কোনো প্রশ্ন না নামে, "Card CSS selector" ঘরে সিলেক্টর বসাতে হবে।
বের করার নিয়ম: ব্রাউজারে প্রশ্নব্যাংক পেজ খুলে `F12` → Elements →
একটা প্রশ্নের বাক্সের উপর মাউস রেখে দেখো তার `class` কী।

### ধাপ ২ — নামানো

"⬇️ সাবজেক্ট নামাও" ট্যাবে সাবজেক্ট বেছে বোতাম চাপো। বাকিটা নিজেই হবে —
কত পেজ আছে বের করে এক এক করে নামাবে, প্রগ্রেস বার দেখাবে।

**প্রথমে ছোট একটা সাবজেক্ট দিয়ে টেস্ট করো** (যেমন ভূগোল, ১১৫টি প্রশ্ন —
৩ মিনিট)। ডেটা ঠিক আসছে, বাংলা ভাঙা নয় — নিশ্চিত হয়ে বড়গুলোয় যাও।

সময়: প্রতি ১৫টি প্রশ্নে ১ পেজ, প্রতি পেজে ২ সেকেন্ড।
সাধারণ জ্ঞান (১৮০০) ≈ ৪ মিনিট। পুরো BCS ≈ ১৭ মিনিট।

> নামানোর সময় ব্রাউজার ট্যাব খোলা রাখো। বন্ধ হলে থেমে যাবে, কিন্তু
> কিছু হারাবে না — আবার চালালে যেখানে থেমেছিল সেখান থেকে শুরু হবে।

### ধাপ ৩ — পাঠ পরিকল্পনা

"📊 পাঠ পরিকল্পনা" ট্যাব বলে দেবে **কয়টা পাঠ লিখলে ৮০% প্রশ্ন কভার হয়**।
পাঠ লেখা শুরুর আগে এই সংখ্যাটা জেনে নাও, নাহলে ১০০+ টপিকে ছড়িয়ে পড়বে।

### ধাপ ৪ — পাঠ লেখা

"✍️ পাঠ লেখা" ট্যাবে প্রতিটি টপিকের জন্য ফর্ম আছে: hook, ব্যাখ্যা,
কেন এমন, উদাহরণ, মনে রাখার কৌশল, সাধারণ ভুল। টপিকগুলো সাজানো আছে
প্রশ্নসংখ্যা অনুযায়ী — উপর থেকে নিচে গেলেই সবচেয়ে কাজের পাঠ আগে হবে।

লেখা শেষ হলে "পাঠ সম্পূর্ণ" টিক দাও। কতটা বাকি তা এক্সপোর্ট ট্যাবে দেখাবে।

### ধাপ ৫ — অ্যাপের ফাইল

"💾 অ্যাপের ফাইল" ট্যাব থেকে `bujhi.db` নামাও।

## ডেটা কাঠামো

```
subjects ──< topics ──< lessons ──< questions
```

| টেবিল | কে ভরে |
|---|---|
| `subjects` | অটো |
| `topics` | অটো (প্রশ্নের ট্যাগ থেকে), অগ্রাধিকার-ক্রমসহ |
| `lessons` | **তুমি** — খালি রো তৈরি হয়ে থাকবে |
| `questions` | অটো, `lesson_id` বসানো |

অ্যাপে পাঠ দেখানোর পর ওই পাঠের প্রশ্ন টানা:

```sql
SELECT * FROM questions WHERE lesson_id = ?;
```

## Flutter-এ বসানো

1. `bujhi.db` → `assets/db/bujhi.db`
2. `pubspec.yaml`-এ assets ঘোষণা করো
3. `sqflite` + `path_provider` দিয়ে প্রথম চালুতে writable ফোল্ডারে কপি করো

## সাধারণ সমস্যা

| সমস্যা | সমাধান |
|---|---|
| `streamlit: command not found` | venv চালু আছে? নাহলে `python -m streamlit run app.py` |
| ০টি প্রশ্ন নামছে | Card CSS selector বসাও |
| বাংলা ভাঙা দেখাচ্ছে | `pip install bijoy2unicode` হয়েছে কিনা দেখো |
| 403 বা 429 এরর | বিরতি ৪-৫ সেকেন্ড করে দাও |
| উত্তর/ব্যাখ্যা ফাঁকা | ওটা AJAX-এ আসে, HTML-এ নেই (নিচে দেখো) |

## উত্তর ও ব্যাখ্যা

সাইটে "Des Please Wait" মানে ব্যাখ্যা আলাদা রিকোয়েস্টে লোড হয়।
`F12 → Network → Fetch/XHR` খুলে একটা প্রশ্নের ব্যাখ্যা বাটনে ক্লিক করো —
তালিকায় যে URL আসবে সেটাই endpoint। `questions` টেবিলে `answer` আর
`explanation` কলাম ফাঁকা রাখা আছে, পরে ভরা যাবে।
