# বুঝি — ডেটা কালেকশন টুল

## ১. VS Code প্রস্তুতি

**এক্সটেনশন ইনস্টল করো** (বাম পাশের Extensions আইকন, বা `Ctrl+Shift+X`):

| এক্সটেনশন | কেন |
|---|---|
| Python (Microsoft) | ইন্টারপ্রেটার, ডিবাগিং, IntelliSense |
| Pylance | অটোকমপ্লিট, টাইপ চেক |
| Ruff | দ্রুত লিন্টিং |

## ২. ফোল্ডার খোলা

`File → Open Folder` → `bujhi-scraper` ফোল্ডারটা সিলেক্ট করো।

## ৩. ভার্চুয়াল এনভায়রনমেন্ট

টার্মিনাল খোলো: `` Ctrl+` ``

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

প্রম্পটের শুরুতে `(.venv)` দেখালে বুঝবে চালু হয়েছে।

তারপর `Ctrl+Shift+P` → `Python: Select Interpreter` → `.venv`-এরটা বেছে নাও।

## ৪. প্যাকেজ ইনস্টল

```bash
pip install -r requirements.txt
```

## ৫. চালানো

```bash
streamlit run app.py
```

ব্রাউজারে `http://localhost:8501` খুলবে। বন্ধ করতে টার্মিনালে `Ctrl+C`।

## কাজের ধাপ

### ধাপ ১ — সিলেক্টর ঠিক করা (একবারই)

"🔍 সিলেক্টর চেক" ট্যাবে গিয়ে **পেজ চেক করো** চাপো।

টেবিলে দেখবে কোন সিলেক্টরে কয়টা ম্যাচ। **১৫-এর কাছাকাছি সংখ্যা** যেটায়, সেটাই আসল
(সাইট প্রতি পেজে ১৫টা প্রশ্ন দেখায়)। ওটা কপি করে সাইডবারের
"Card CSS selector" বক্সে বসাও।

নিচে "অটো-পার্স ফলাফল" যদি ইতিমধ্যে ১৫ দেখায়, তাহলে সিলেক্টর খালি রাখলেও চলবে।

### ধাপ ২ — অল্প করে টেস্ট

প্রথমে **শেষ পেজ = ৩** দিয়ে চালাও। ৪৫টা প্রশ্ন এলে আর বাংলা ঠিকমতো দেখালে
তারপর বড় রেঞ্জে যাও।

### ধাপ ৩ — টপিক বিশ্লেষণ

"📊 টপিক বিশ্লেষণ" ট্যাব বলে দেবে কোন কয়টা পাঠ লিখলে ৮০% প্রশ্ন কভার হয়।
**পাঠ লেখা শুরু করার আগে এটা দেখে নাও** — নাহলে কম গুরুত্বপূর্ণ টপিকে সময় যাবে।

### ধাপ ৪ — এক্সপোর্ট

"💾 এক্সপোর্ট" ট্যাব থেকে **পাঠ টেমপ্লেট** নামাও। এতে টপিক ধরে প্রশ্ন গ্রুপ করা
থাকবে, আর `concept` / `why` / `mnemonic` ফিল্ড ফাঁকা থাকবে —
NCTB/খায়রুল'স PDF পড়ে ওগুলো ভরাই তোমার আসল কাজ।

## সাধারণ সমস্যা

| সমস্যা | সমাধান |
|---|---|
| `streamlit: command not found` | venv চালু আছে কিনা দেখো, না থাকলে `python -m streamlit run app.py` |
| ০টি প্রশ্ন আসছে | ধাপ ১ আবার করো, সিলেক্টর ভুল |
| বাংলা লেখা ভাঙা | `pip install bijoy2unicode` হয়েছে কিনা দেখো |
| 403 / 429 এরর | বিরতি ৪-৫ সেকেন্ড করে দাও |
| উত্তর/ব্যাখ্যা আসছে না | ওটা AJAX-এ লোড হয় — HTML-এ নেই |

## উত্তর ও ব্যাখ্যা প্রসঙ্গে

সাইটে "Des Please Wait" লেখাটা মানে ব্যাখ্যা আলাদা রিকোয়েস্টে আসে।
বের করতে: ব্রাউজারে `F12 → Network → Fetch/XHR` খুলে একটা প্রশ্নের
ব্যাখ্যা বাটনে ক্লিক করো। যে URL-টা তালিকায় আসবে সেটাই endpoint।
ওটা পেলে `scraper.py`-তে একটা ফাংশন যোগ করে নিতে পারবে।

## সব সাবজেক্ট একসাথে নামানো

`app.py` একটা করে সাবজেক্টের জন্য। পুরোটা নামাতে CLI স্ক্রিপ্ট:

```bash
# ১. আগে দেখো কী কী সাবজেক্ট আছে
python download_all.py bcs-preliminary --list

# ২. সব নামাও
python download_all.py bcs-preliminary --selector "div.single-question"

# ৩. অথবা শুধু কয়েকটা
python download_all.py bcs-preliminary --only বাংলা english গণিত
```

`--selector` এ সেই সিলেক্টরটা দাও যেটা UI-র "সিলেক্টর চেক" ট্যাবে ১৫ দেখিয়েছিল।

### যা তৈরি হবে

```
data/bcs-preliminary/
├── সাধারণ-জ্ঞান.json
├── সাধারণ-জ্ঞান.state.json     ← কোন পেজ শেষ, তার হিসাব
├── বাংলা.json
├── english.json
└── merged.json                  ← সব একসাথে, ডুপ্লিকেট বাদ
```

### মাঝপথে থামলে

`Ctrl+C` চাপো বা কারেন্ট চলে যাক — সমস্যা নেই। প্রতি ৫ পেজে সেভ হয়।
একই কমান্ড আবার চালালে যে পেজগুলো হয়ে গেছে সেগুলো বাদ দিয়ে বাকিটা নামাবে।

### সময়

BCS প্রিলিতে ~৭,৩০০ প্রশ্ন = ~৪৯০ পেজ। ২ সেকেন্ড বিরতিতে **~১৭ মিনিট**।
রাতে চালিয়ে রেখে দিলেই হয়। `--delay 3` দিলে নিরাপদ, সময় ~২৫ মিনিট।
